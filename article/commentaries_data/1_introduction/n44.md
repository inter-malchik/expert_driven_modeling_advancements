Paper A (Gindullina et al., Expert-Guided PINN) runs an expert-in-the-loop cycle where an LLM edits SIRD-PINN loss code and the system **must retrain** before anyone can judge the forecast. Paper B (Zwirn & Delahaye, *Unpredictability and Computational Irreducibility*) proves that for computationally irreducible (CIR) systems there is **no shortcut** to the $n^{\text{th}}$ state faster than stepwise simulation. The thesis: Gindullina’s architecture **institutionalises** CIR-style epistemology (macro epidemic curves knowable only after running the PINN) while still tempting users to believe NL edits compress that path—hence high compile rates beside 25–27% semantic compliance (Comparative inference).

## Sources & Evidence

This section ties the CIR framing to verbatim citations from the local Zwirn & Delahaye transcription.

1) Claim: "If behavior is computationally irreducible, no computation of the n‑th state can be faster than the simulation itself."
   - Evidence: Zwirn & Delahaye (2013), Introduction / formal statement.
   - Quotes (verbatim):
     > "…we propose a robust formal definition… of ‘to be unable to compute the $n^{\text{th}}$ step without having to follow the same path…’… this implies… that if the behavior of an object is computationally irreducible, no computation of its $n^{\text{th}}$ state can be faster than the simulation itself." (Intro, lines 8–9)

2) Claim: "Determinism does not guarantee predictability; unpredictability arises even in deterministic systems (chaos, undecidability)."
   - Evidence: Zwirn & Delahaye (2013), §1 Introduction.
   - Quotes (verbatim):
     > "It is now common knowledge that it is not because the behavior of a system is deterministic that it is possible to predict it… [We] know that even if a system is deterministic it can be the case that we can't predict its behavior in the long run." (§1, lines 14–15)
