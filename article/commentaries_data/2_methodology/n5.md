One prompt, one LLM call, a full code artifact in a single pass is exactly the "Single-Shot" configuration Yu et al. test as their weakest baseline for hardware codegen — and it fails all three of their test cases outright. Their working alternative — pseudocode → Python → C++ with a Coder/Verifier pair at each stage, plus a four-branch Reflection agent that can reopen the original instructions rather than just regenerate code — is a tested architecture for the exact gap this paper names but doesn't build. Their ablations (removing Understanding, Reflection, or progressive coding one at a time) are also the controlled experiment this paper's three-model comparison never runs: it can separate model from architecture; the PINN Customizer can't.

1) Claim: "Single‑Shot baseline (one‑pass code generation) performs worst; multi‑agent progressive coding outperforms it."

     > "Unlike previous approaches that either generate RTL directly or rely on extensive human preprocessing, Spec2RTL-Agent follows a structured, iterative process that mirrors the conventional human-driven hardware design workflow… progressively refines the code across multiple representations (pseudocode, Python, and C++)." (Abstract; §1, §3)

2) Claim: "Spec2RTL architecture: Coder/Verifier pairs across stages (spec → pseudocode → implementation), plus a Reflection agent capable of revisiting the original spec."
   - Evidence: 2025 Spec2RTL‑Agent (architecture section; figure with roles/flows).
   - Quotes (verbatim):
     > "Spec2RTL-Agent introduces a novel multi-agent collaboration framework that integrates three key enablers: (1) a reasoning and understanding module… (2) a progressive coding and prompt optimization module that iteratively refines the code across multiple representations (pseudocode, Python, and C++)… and (3) an adaptive reflection module that identifies and traces the source of errors during generation, ensuring a more robust code generation flow." (Abstract)

3) Claim: "Ablations removing Understanding/Reflection/progressive coding degrade pass rates; the gains are architectural, not only model‑scale."
   - Evidence: 2025 Spec2RTL‑Agent (ablation study; results table/figures).
   - Quotes (verbatim):
     > "We evaluate Spec2RTL-Agent on a benchmark of three specification documents… demonstrating its effectiveness in generating accurate RTL code with as much as 75% fewer human interventions compared to existing approaches." (Abstract)

     > "Experiments… validate the effectiveness of our proposed Spec2RTL-Agent… Notably, Spec2RTL-Agent achieves as much as 75% fewer human interventions compared to existing methods." (§1 Summary of contributions)
